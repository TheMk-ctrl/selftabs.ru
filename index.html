Презентация Selftabs

Единая экосистема парковки & аналитики вкладок Selftabs

Selftabs превращает хаос из десятков открытых страниц в структурированные сессии, высвобождает RAM, предоставляет AI-дайджесты и объединяет команды через совместные Workspace сессии.

Расширение v1.0.0

Установка на ПК, парковка сессий, прямое перетаскивание вкладки в браузер через drag-and-drop, ограничение вкладок, точечные фильтры и контроль RAM.

Десктоп Приложение

Управление категориями и папками под разные задачи, кастомизация дизайна в стиле MyWallet, автономный режим и быстрая локальная синхронизация.

Telegram Бот & Mini App

Рассылки, напоминание об истекающей подписке, 2FA подтверждение входа, поиск людей по юзернейму, просмотр профилей, графов статистики и сессий.

Self vs Workspace

Пространства

Разделение личных и командных сессий в один клик.

  • Self: Персональные сессии, всё твое, полная приватность и бесплатный доступ.
  • Workspace ($10/мес): Командный доступ до 10 человек (экономия в 2 раза), доступ к «общим» сессиям.
  • Управление: Выбор конкретных вкладок для перемещения или удаления из Workspace.

AI Модуль & Дайджесты

Интеллект

Автоматический анализ прочитанного контента.

  • 7-дневный брифинг: Еженедельные weekly дайджесты сохраненных сайтов.
  • Сводка по странице: Мгновенный пересказ открытой вкладки прямо в браузер.
  • Свой API Ключ ИИ: Подключение персонального OpenAI/Claude API ключа.

Профиль & Кастомизация

  • • Профиль: Аватарка, Юзернейм, Имя, Био, Статус-кольцо (Pro, Team).
  • • Дизайн: Адаптивная тема (#1A0A3A, #FFF, #C5B5F9), шрифт Iosevka Charon Mono.
  • • Кастомизация папок (Pro): Размытие (blur), анимации, сезонное оформление, точечная настройка дизайна в стиле MyWallet.
  • • Интеграция сервисов: Telegram, Google, Notion, Gmail.

Безопасность & Резервирование

  • • Безопасность: Шифрование данных, Код-пароль, 2FA с Telegram, Почта для входа, Список устройств.
  • • Исключения: Настройка сайтов-исключений для авто-парковок.
  • • Экспорт: Экспорт сессий в JSON и Markdown, авто-бэкап по интервалам, облачная синхронизация (Pro).
  • • Telegram: Поиск людей по юзернейму, просмотр сессий и графа статистики, переключатель публичного показа.
